 REFERENCE DESK

Coverage & tools

This is a searchable starting reference, not all existing Ford base numbers. It includes a public, undated reference with historical vehicle examples; those entries have not been individually verified against Ford’s current catalog.

Names and descriptions suggest candidate families. They do not establish fitment, supersessions or engineering-to-service interchange. Selected entries have been checked against Snap-on EPC and include their catalog context. The app does not have a live EPC connection or a full catalog export.

Use on your phone

Open the install page for the install button and phone-specific help.

In Chrome, open the browser menu and choose Add to Home screen or Install app if offered. In Safari, use Share → Add to Home Screen. Installation options depend on your browser and private sign-in.

Online access may be required to sign in. After a successful load, the app caches its built-in reference for offline use where the browser allows it. Imports do not sync between devices.
